# Prisma MCP server (archived)

This repository is archived and no longer maintained.

Prisma's MCP server is hosted at https://mcp.prisma.io/mcp (Streamable HTTP). It manages Prisma Postgres databases and existing Prisma Compute apps. Sign in with a Prisma account when you connect. The server does not build or upload code.

- Setup for each AI tool: https://www.prisma.io/docs/ai/tools/mcp-server
- Tool reference: https://www.prisma.io/docs/ai/mcp-tools

The local server (`npx prisma mcp`) was part of the Prisma ORM CLI from 6.6 to 7.x. It is not in Prisma 8.
